# 制作提示词（学习整理版）

方法参考：**Git源宝**的[B站教程](https://www.bilibili.com/video/BV1ALnw6YEM7/)与[飞书配套资料](https://gcnw06d95nrz.feishu.cn/docx/KtSgdMmi7oCZS2xqMKXcWCKqndc)。本项目在 AI 辅助下概括制作思路，并结合统一时间轴、环境复用和导出核验要求重新编写以下三组模板；没有收录原版完整提示词，不宣称相关方法由本项目首创。

来源、改写范围及许可边界见 [../NOTICE.md](../NOTICE.md)。本文件的许可不授予原教程材料的权利；另行使用原文或原版模板时应核实授权。

## 策划

```text
请围绕【主题】为【受众】设计一支【时长、平台、画幅】的科普动画。
先界定一个核心问题，核查重要事实，写出有来源的简短脚本。
输出动态分镜表：场景ID、起始帧、时长、知识点、初始状态、变化过程、结果、字幕与来源。
采用【风格】，规定配色含义、字体层级和图形规则。
每段用可见的变化解释关系，避免只让标题和定义轮流出现。
统一总帧数，标记仍需核实的内容。
```

## 实现

```text
请按分镜在当前 Remotion 工程中实现动画。
先检查工程和依赖，复用现有环境；不要覆盖不相关内容。
场景、字幕和声音使用同一份时间配置，图形组件和视觉主题分离。
所有效果按帧驱动，随机效果固定种子，确保预览与渲染一致。
逐场景检查中文、换行、布局、字幕重叠、阅读时间和切点，再实际导出 MP4。
交付成片、可编辑工程、分镜与来源记录，说明实际完成和验证范围。
```

## 局部修改

```text
修改场景【ID】：当前问题是【可观察现象】。
将变化过程改为【新的演示方式】，保留【已确定的事实和视觉规则】。
若需调整时长，重新平衡相邻场景并保持整片总帧数。
检查该段与前后镜头的衔接，然后重新渲染受影响的部分与最终成片。
```
