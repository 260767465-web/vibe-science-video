# 15 种风格的选择指南

以下由维护者独立概括，用于选择图形语言和实现路线。名称与分类受到 Git源宝教程启发；不是原版模板全文，也不意味着已提供 15 个可直接渲染的工程。原始资料链接见 [../NOTICE.md](../NOTICE.md)。

| 风格 | 适合说明什么 | 设计时关注什么 |
| --- | --- | --- |
| 手绘动画 | 生活比喻、故事型解释 | 纸感、略有变化的轮廓、低帧节奏和夸张动作；输出帧率与造型更新频率可以不同 |
| 信息贴纸 | 数字、地图、日常知识 | 白底标签、粗中文、少量重点色；让数字增长、地图连线和图表变化直接对应事实 |
| 复古拼贴 | 历史、文化、档案叙事 | 有来源的影像、纸边和分层揭示；避免装饰纹理淹没出处和文字 |
| 像素游戏 | 游戏知识、怀旧类比 | 固定像素网格、有限色盘、整数放大和阶梯运动，避免亚像素模糊 |
| 竖屏综艺 | 事件、情绪和短片包装 | 花字紧跟事件，保护主体动作与字幕安全区；不能以包装代替原理演示 |
| 极简几何 | 概率、逻辑、流程和比较 | 用少量几何对象表达关系，错峰进入，重点变化有明确的节拍 |
| 金色描线 | 路径、网络、连续关系 | 深色底与细线，路径逐步生长；转弯和连接处连续，留白足够 |
| 现代主义 | 构成、系统和品牌解释 | 网格、基本形状与有限原色；重心、对齐和运动落点精确 |
| 图形变形 | 概念转译、结构关联 | 保持重心、方向和轮廓演变连贯；不能用物体突然替换冒充连续形变 |
| 柔软立体 | 材料感、产品和空间交互 | 圆润体块、接触、光照与惯性一致；确认是否真的需要三维 |
| 等距微缩 | 城市、网络、工厂和复杂系统 | 稳定正交视角，让模块生长或流动显示组成关系，保持接地与透视一致 |
| 赛博朋克 | 扫描、监控、技术系统 | 面板、雷达和数据变化具有功能含义，不随机堆叠闪光线条 |
| 玻璃拟态 | App、界面和信息层级 | 半透明分层与克制的背景模糊，优先保证文字对比度和渲染稳定性 |
| 霓虹网格 | 速度、复古科技和音乐视觉 | 地平线、消失点和前进方向一致，扫描线与光晕保持克制 |
| 果冻流体 | 连续融合、流动和视觉片头 | 张力、体积、黏度与高光连续；复杂流体通常需要着色器或三维路线 |

选型建议：抽象关系先考虑几何或线条，具体数字先考虑信息贴纸，空间组成再考虑等距结构。风格是表达选择，不是成片质量或制作时间的保证。
